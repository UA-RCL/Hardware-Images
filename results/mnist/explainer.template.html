Count spikes down each class column

The predicted digit is the class with the largest spike count. A tie selects the lowest digit index.

These counts are not probabilities. Fifteen spikes means fifteen of that class's 25 neurons fired; several class neurons in the same row can fire.

What this trace explains

The maps show the actual configured arithmetic: which binary pixels contributed, which hidden neurons fired, and which output neurons added votes. Blue and red maps are signed contributions, not a saliency estimate or named shape detector.

What was measured

Hidden states are reconstructed; FPGA internal neuron signals were not probed. Final output masks are directly recorded board results, checked against saved simulator rows and the reconstruction.
